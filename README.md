# Transmute ⚡

**A lightning-fast, privacy-first Smart File Toolkit.**

Transmute is a premium, mobile-optimized web application designed to handle all your essential file manipulation needs without sacrificing privacy. Unlike cloud converters that store your sensitive data, Transmute processes files securely and instantly.

## ✨ Features

Transmute includes exactly 10 highly optimized, essential file tools:

**Image Tools**
- **PNG → JPG / JPG → PNG**: Lightning-fast image format conversion.
- **WebP → JPG / PNG**: Make modern web images universally compatible.
- **Compress Image**: Drastically reduce file size while maintaining visual quality.
- **Resize Image**: Scale images perfectly by percentage for web or print.

**PDF Tools**
- **Merge PDFs**: Combine multiple PDF documents into a single, seamless file.
- **Split PDF**: Break apart massive PDFs into individual, manageable pages.
- **Compress PDF**: Shrink bulky PDF files for easy email attachments.
- **Image → PDF**: Compile single or multiple images into a professional PDF document.
- **PDF → Images**: Extract every page of a PDF into high-quality PNGs or JPGs.
- **PDF → Word (DOCX)**: Extract text from locked PDFs into editable Microsoft Word documents.

## 🚀 Why Transmute?
- **Universal Previews:** Built-in engine to visually preview extracted ZIP contents, Word documents, and PDFs directly in your browser before downloading.
- **Dark & Light Mode:** Beautiful, responsive UI that instantly toggles between a soft parchment light theme and a pitch-dark aesthetic.
- **Mobile First:** The interface flawlessly transforms from a desktop dashboard into a swipeable, touch-friendly mobile app.
- **Zero Data Retention:** Built with a strict privacy-first architecture. 

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, CSS3 (Custom Variables/Grid/Flexbox), Vanilla JavaScript
- **Backend:** Node.js, Express.js
- **Processing Engines:** `sharp` (Image Processing), `pdf-lib` & `pdfjs-dist` (PDF Manipulation), `docx` (Word Generation)
- **Client-side Renderers:** `jszip` & `mammoth.js`
